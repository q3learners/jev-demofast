# Shot List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The founder's script comes with a shot list of pages from the map. The recorder visits every shot, then
runs the brief's task if there is one. The voice-over is budgeted per shot.

**Architecture:**
- `narrate/shots.py` decides which map pages can be shots and validates the model's list.
- `story.write` asks for `{"script", "shots"}` and writes `story.txt` and `shots.json`.
- A new `drive/tour.py` plays the shots with the existing Session and Recorder, then hands the task shot to the goal
  loop, which is extracted from `jev_drive.run`.
- `fit.write` gets each segment's `show` and a per-shot budget.

**Tech Stack:** Python 3.12, pytest, browser-harness CDP, Nemotron on Nebius via `cf.chat`.

**Spec:** `docs/superpowers/specs/2026-10-27-shot-list-design.md`

## Global Constraints

- `MAX_SHOTS = 6`, not counting the home opening, which is always first.
- `SCROLL_STEPS = 2`, each about one screen.
- No invented shots:
  - Pages not in the map are dropped and logged.
  - With no valid shot, the demo falls back to today's goal run, and the log says so.
- Error pages are never offered. The test is a page whose map texts are empty, or whose first text starts with a
  3-digit HTTP status ("429 Too Many Requests", "404").
- No hardcoded list of route words.
- Voice-over budget:
  - 20 words for the first moment of each shot, plus 8 for each further moment in that shot.
  - Segments without a `shot` keep 13 each, as today.
- `jev-demofast run` (single goal) and all 205 existing tests keep passing.

## Review Focus

- **The model returns prose or fenced JSON instead of JSON.** The script is still written, with no shots; the demo runs
  as today. Test in Task 2.
- **A shot's page redirects to a subdomain** (`/campus` → `campus.tutorq.ai`). It counts as arrived, not skipped.
  Test in Task 4.
- **A shot whose link isn't on screen.** It goes there directly and is still recorded. Test in Task 4.
- **A shot page that won't load, or leaves the site.** It is skipped, the tour continues, and the verdict is not
  confirmed. Test in Task 4.
- **A short page that can't scroll.** No empty "look" moments are recorded. Test in Task 4.

### Task 4: The tour visits every shot

**Files:**
- Create: `src/jev_demofast/drive/tour.py`
- Test: `tests/test_tour.py`

**Interfaces:**
- Consumes: `click_on_camera`, `drive_goal` (Task 3); `first_screen`, `covered`, `clear_popups` (popups); Session;
  Recorder; `on_site`.
- Produces: `tour.run(cf, url, shots, index, out=None, fresh=False, dry_run=False, log=print) -> dict`. It has the
  same keys as `jev_drive.run`'s result, plus `"skipped": [pages]`.
  - **Opening:** the same as `jev_drive.run`: first_screen, snap, re-snap if covered. It commits
    `{"do": "open", "shot": 0, "show": shots[0]["show"]}`.
  - **Each page shot `i`:**
    - If already on the page, it skips navigation.
    - Otherwise it looks for a visible clickable element whose `s.href` path equals the page. If found,
      `click_on_camera(..., {"do": "click", "target": label, "shot": i, "show": show})`.
    - Otherwise it uses `Page.navigate` (a cut) and commits `{"do": "go", "target": page, "shot": i, "show": show}`.
    - **Arrived** means `on_site(url, s.host)` and (the path equals the page, or the host differs from `s.host`,
      i.e. a redirect to a subdomain).
    - Otherwise, or on TimeoutError or LEFT_SITE, the shot is skipped: logged "skipped shot /x: <why>", appended to
      `skipped`, with the pending frames discarded.
  - **Show:** up to `SCROLL_STEPS = 2` times, while `scrollY + innerHeight < scrollHeight - 40`:
    - Scroll by `0.8 * innerHeight`, wait for the page, and `snap(1.5)`.
    - Commit `{"do": "look", "shot": i, "show": show, "headings": [visible h1–h3, max 4]}`.
  - **Task shot:** `drive_goal(cf, s, rec, task, index, 12, log, ms)`. Its segments get `shot` and `show` set after
    the fact (every action appended during it).
  - **Verdict:**
    - verified = no page shot skipped, and the task (if any) verified.
    - Otherwise `rec.unconfirmed(why)`, where why is "couldn't show /x" or the task's why.
  - **Finally:** it calls `rec.save(goal_text, cf.decisions)` with goal_text = the task, else "tour: " + the shot
    pages; then `s.close()`. It logs the same `done in …` line as `run`.
- [ ] **Step 1: Write the failing tests** with a fake Session.
